Gestão de Estoque 

Sistema simples de gerenciamento e controle de estoque desenvolvido em PHP e MySQL utilizando PDO.

Tecnologias

PHP 
MySQL (PDO)
HTML
XAMPP

Configuração Básica

Servidor: Inicie o Apache e MySQL no XAMPP.

Banco de Dados:

Crie o banco gestao_estoque no phpMyAdmin.
Importe o arquivo database.sql.
Conexão (config/database.php):
Ajuste a porta se necessário (ex: localhost;port=6608).
